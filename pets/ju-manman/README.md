# 橘慢慢

由 Zhengjiazhi 创作的黄色河马搭档。橘慢慢总是半眯着眼、头顶一颗小橘子，穿着蓝色星星小裤衩，动作克制而淡定。

![橘慢慢动态预览](preview.gif)

## 动作

- 轻微呼吸与短暂停顿的安静待机。
- 小步左右移动，不做夸张摆动。
- 克制地挥手、跳起与表现失败状态。
- 清晰区分等待、处理中与审查状态。
- 包含 16 个连续观察方向。

## 兼容性

- Codex pet sprite version：2
- 图集：透明 WebP，1536 × 2288
- 布局：8 列 × 11 行，单格 192 × 208
