# 奶豆

由 Zhengjiazhi 创作的原创奶白色短绒小豆子。奶豆有一双迷糊的蚊香圈眼，动作缓慢、柔软，常常歪头发呆。

![奶豆动态预览](preview.gif)

## 动作

- 小幅左右摇摆与发呆的安静待机。
- 慢悠悠的左右移动。
- 轻轻挥手、跳起与失败瘫倒。
- 清晰区分等待、处理中与审查状态。
- 包含 16 个连续观察方向。
