# 刀盾柴犬

由 Zhengjiazhi 创作的原创 3D 柴犬战士。它有圆润结实的体型、赤棕色毛发与奶油色胸腹，一只前爪握短刀，另一只前爪持盾。

![刀盾柴犬动态预览](preview.gif)

## 动作

- 平稳呼吸、眨眼的安静待机。
- 清晰交替的左右移动步态。
- 挥手、跳跃与低头受挫动画。
- 区分等待、处理中与审查状态。
- 包含 16 个连续观察方向。

## 兼容性

- Codex pet sprite version：2
- 图集：透明 WebP，1536 × 2288
- 布局：8 列 × 11 行，单格 192 × 208
