# 白曜机甲

由 Zhengjiazhi 创作的原创白色 AI 机甲。动作风格沉稳克制，全程保持机器人形态。动画、图集结构、16 个观察方向与视觉去品牌检查均已通过。

![白曜机甲动态预览](preview.gif)

## 动作

- 轻微呼吸与眨眼的安静待机。
- 重心稳定的左右短步移动。
- 克制挥手、低幅悬停、平稳恢复。
- 清晰区分等待、处理中与审查状态。
- 包含 16 个观察方向。

## 兼容性

- Codex pet sprite version：2
- 图集：透明 WebP，1536 × 2288
- 布局：8 列 × 11 行，单格 192 × 208
